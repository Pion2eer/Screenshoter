# Скриншотер

Лёгкий скриншотер для Windows 10/11: делаешь несколько скринов с подписями, стрелками и рамками,
потом одним **Ctrl+V** вставляешь их все разом, например в чат Claude.

## Запуск

1. **До распаковки** нажми правой кнопкой на `Screenshoter.zip` → «Свойства» → внизу поставь галочку
   «Разблокировать» → OK. Тогда Windows не будет ругаться при запуске (иначе она помечает всё скачанное
   из интернета как подозрительное).
2. Распакуй архив в любую папку, например `C:\Tools\Screenshoter`.
3. Запусти `Screenshoter.exe`. В трее появится жёлтая иконка.

Если уже распаковал без разблокировки — правый клик на `Screenshoter.exe` → «Свойства» → «Разблокировать».
Другой способ без предупреждений: запусти `build.bat`, он соберёт свой `Screenshoter.exe` прямо на твоём компьютере.
4. Чтобы запускался сам: правый клик по иконке → «Запускать вместе с Windows».

Ничего устанавливать не нужно: .NET Framework 4.8 уже есть в Windows 10/11.

## Как пользоваться

1. **Win+Shift+S** (вместо системных «Ножниц») — экран замирает и затемняется.
2. Выдели область мышью. Просто клик — весь монитор. Кнопка «Весь экран» или клавиша **F** — тоже.
   После выделения сразу включена **стрелка**.
3. Добавь пометки (инструмент выбирается кнопкой на панели или клавишей):
   - **T — Подпись.** Клик — жёлтая плашка в этом месте, пиши текст.
     **Зажми мышь на объекте и протяни** в сторону — плашка встанет там, где отпустил, со стрелкой на объект.
     Enter — новая строка (длинный текст и так переносится сам). Esc или клик мимо — закончить подпись.
     Плашку можно перетаскивать, клик по ней — редактировать.
   - **A — Стрелка** (включена по умолчанию). Зажми мышь на объекте и тяни туда, где будет текст:
     остриё у объекта, плашка там, где отпустил. Просто клик без протягивания — подпись без стрелки.
     На хвосте стрелки сразу появляется плашка для текста. Не нужен текст — нажми Enter или Esc, останется просто стрелка.
   - **R — Рамка** (обвести объект), **M — Маркер** (выделить блок полупрозрачным жёлтым).
   - **P — Карандаш**: рисуй от руки.
   - **N или кнопка «⟲ Новая пачка»** — сбросить накопленные скрины, текущий станет первым.
   - Правый клик по пометке — удалить. **Ctrl+Z** — отменить последнюю.
4. **Enter** (когда не пишешь подпись) или **Ctrl+Enter** — скрин добавлен в пачку и уже лежит в буфере. **Esc** — отмена.
5. Повтори сколько нужно, затем в чате **Ctrl+V** — прикрепятся все скрины.

Скрины пронумерованы (жёлтый кружок в углу), чтобы было удобно писать ИИ «на скрине 2…».
Номер отключается в меню трея.

## Как работает вставка нескольких картинок

Буфер обмена Windows умеет хранить только одну картинку, поэтому каждый скрин сохраняется PNG-файлом
в `%TEMP%\Screenshoter\`, а в буфер кладётся **список файлов** (как при Ctrl+C файлов в Проводнике).
Claude, ChatGPT, Gemini, Telegram, Discord прикрепляют их все одним Ctrl+V.

Если какая-то программа принимает только одну картинку — в меню трея выбери
«Склеивать в одну картинку»: пачка склеится в одно длинное изображение.

**Скрины из пачки не пропадают.** Если между скринами ты скопировал что-то другое (или буфер перезаписала
другая программа, например Parsec), следующий скрин снова положит в буфер всю пачку целиком.

**Новая пачка начинается** только после того, как ты вставил пачку по Ctrl+V (вставить можно и повторно,
пока не сделал новый скрин), или по кнопке «⟲ Новая пачка» / пункту в меню трея. Если пачку случайно сбросил —
«Вернуть прошлую пачку в буфер» в меню трея. Временные файлы хранятся 3 дня.

## Меню в трее (правый клик по иконке)

Сделать скриншот · Начать новую пачку · Вернуть прошлую пачку · Отдельными картинками / Склеивать · Номер скрина в углу ·
После Ctrl+V начинать новую пачку · Перехватывать Win+Shift+S · Перехватывать PrtSc ·
Запускать вместе с Windows · Отключить системные «Ножницы» на Win+Shift+S · Открыть папку со скриншотами · Выход.

Настройки хранятся в `%APPDATA%\Screenshoter\settings.ini`.

## Обновление

В меню трея есть «Проверить обновления». Программа смотрит последний релиз на GitHub (Pion2eer/Screenshoter → Releases), и если там версия новее, скачивает её, подменяет exe и перезапускается. Через полминуты после запуска проверка проходит тихо сама: всплывёт уведомление, только если вышла новая версия.

Как выпустить новую версию: запушь тег, например `git tag v1.1.0 && git push origin v1.1.0`, или запусти workflow «Release» во вкладке Actions с номером версии. GitHub сам соберёт exe и выложит релиз. Для работы обновлений репозиторий должен быть публичным.

## Сборка из исходников

Запусти `build.bat` — он соберёт `Screenshoter.exe` встроенным в Windows компилятором за пару секунд.

## Если вместе с нашим окном открываются системные «Ножницы»

Правый клик по иконке в трее → «Отключить системные «Ножницы» на Win+Shift+S». Программа пропишет в реестр
`HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced\DisabledHotkeys = S` и перезапустит Проводник.
Побочный эффект: перестанет работать Win+S (поиск), обычный поиск через «Пуск» останется. Повторный клик всё возвращает.
